# 영어 학습 가이드라인

> 영어 학습 세션의 초기 테스트, 레벨 기준, 주제 선택에 사용하는 공통 지침입니다.

---

## 초기 실력 테스트 (첫 세션 전용)

학습 프로필에 테스트 결과가 없을 경우, 정규 세션 시작 전에 아래 테스트를 진행합니다.

### 테스트 구성

1. **어휘 (5문제)**: 단어의 올바른 뜻을 고르는 사지선다
2. **문법 (5문제)**: 올바른 문장 선택 또는 빈칸 채우기
3. **독해 (1지문 + 3문제)**: 짧은 단락 읽고 이해도 확인
4. **자기표현 (1문제)**: 자신에 대해 영어로 1~2문장 작성

### 채점 기준

| 점수 | 레벨 | 설명 |
|------|------|------|
| 0–6점 | A1 | 완전 초급 |
| 7–10점 | A2 | 초급 |
| 11–13점 | B1 | 초중급 — 세션 난이도를 상향 조정 |

테스트 결과는 학습 데이터베이스에 저장합니다.

---

## 레벨 기준 설명

| 레벨 | 명칭 | 수준 설명 |
|------|------|-----------|
| A1 | 완전 초급 | 인사말, 숫자, 아주 기본적인 단어 수준 |
| A2 | 초급 | 기본 문장 이해·표현 가능. 여행 간단한 의사소통 가능 |
| B1 | 초중급 | 일상 대화 가능, 짧은 글 작성 가능 |
| B2 | 중급 | 자연스러운 대화, 뉴스 기사 이해 가능 |
| C1/C2 | 고급 | 원어민 수준 |

## 학습 주제 로테이션 목록

세션마다 아래 주제를 순환하며 사용합니다.
주제 그룹 간 균형 있게 순환하되, 학습자 요청 시 특정 그룹을 집중 선택할 수 있습니다.

### 여행 / 일상
- 공항 (Airport)
- 호텔 (Hotel)
- 식당 (Restaurant)
- 쇼핑 (Shopping)
- 길 찾기 (Directions)
- 일상 루틴 (Daily routine)

### 비즈니스 영어
- 이메일 작성 (Business email writing) — 요청, 확인, 거절 표현
- 회의 표현 (Meetings & calls) — 의견 제시, 동의/반대, 일정 조율
- 보고서 / 문서 읽기 (Reports & memos) — 요약, 핵심 파악
- 협업 / 프로젝트 커뮤니케이션 (Project communication) — Slack/Jira 스타일 표현
